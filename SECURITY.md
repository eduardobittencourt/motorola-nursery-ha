# Security policy

## Supported versions

Security fixes are applied to the latest published version and the default
branch. Users should upgrade to the newest available version before reporting a
problem that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/eduardobittencourt/motorola-nursery-ha/security/advisories/new)
and include:

- the affected version or commit;
- a minimal reproduction or clear attack scenario;
- the expected security impact;
- any suggested mitigation, if known.

Remove real email addresses, account and device identifiers, local addresses,
stream URLs, email codes, tokens, and camera credentials. Synthetic examples are
preferred. Do not send APKs, firmware, proprietary libraries, or unrelated
personal data.

The maintainer will acknowledge a complete report when practical, investigate
it privately, and coordinate a fix and disclosure. Reports that require access
to someone else's camera or account without authorization are not accepted.
