## Keeping the documentation current

Technical guides are versioned with the implementation. Update the relevant
guide when changing a transport, field mapping, lifecycle or maintenance step.
State the tested model and firmware, and distinguish verified behavior from
research hypotheses. Keep development-session diaries, personal deployment
notes, credentials and raw captures outside the public documentation.
